# Agent instructions

## Backlog (GitHub Issues)

The product backlog lives in [GitHub Issues](https://github.com/wlatanowicz/punch-card/issues). Agents must follow the **github-backlog** skill when creating, updating, or implementing from issues.

### Issue format

Each issue uses sections: **Summary**, **Why**, **Scope**; optionally **Out-of-Scope** and **Dependencies** (`Depends on`, `Blocks`, `Related to`).

### Labels

Use exactly one of: `enhancement`, `bug`.

### Commits

Commits for issue work must reference the issue (for example `(#123)` in the subject or `Refs #123` in the body).

### Closing issues

**Close policy:** Reference-only — use `Refs #N` in commits; humans close issues when done.
